# REAL Color Mate

Portable Color Measurement Tool for Automotive Paint Matching.

## Project

REAL Color Mate is a portable measurement system for automotive paint color matching.
The project is being developed as a practical, reproducible, and maintainable tool for automotive repair environments.

## Authority

**`MASTER_SPECIFICATION.md` is the Single Source of Truth for formal project specifications.**

Operational rules, plans, ideas, and design history are maintained separately.

## Current Development Status

The documentation foundation is established.

The next development phase is **Phase 1 — Component and Requirement Verification** as defined in [ROADMAP.md](./ROADMAP.md).

Priority verification items include purchased component dimensions, AS7341 documentation, display-module dimensions, optical placement requirements, and the power-system requirements.

## Development Rules

- Formal specifications must be taken from `MASTER_SPECIFICATION.md`.
- Do not guess technical values.
- Use `Unknown` when information cannot be verified.
- Do not treat roadmap items or ideas as approved requirements.
- Keep hardware, software, optical, mechanical, calibration, and manufacturing documentation internally consistent.
